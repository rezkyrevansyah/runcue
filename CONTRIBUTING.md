# Contributing to RunCue

Thanks for your interest in improving RunCue.

## How to contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Make your improvements with clear, focused commits.
4. Run the project locally and verify the feature works.
5. Open a pull request with a short description of the change.

## Development setup

```bash
git clone https://github.com/rezkyrevansyah/runcue.git
cd runcue
npm install
npm run dev
```

## Code conventions

- Use TypeScript and prefer clear, readable component structure.
- Keep functions small and focused.
- Maintain the mobile-first UX principle.
- Do not add unnecessary dependencies if a simple solution works.
- If you change workout logic, test the flow with real user scenarios.

## Pull request checklist

- Feature or fix is clearly explained
- Documentation is updated when needed
- Code builds without errors
- UI changes remain simple and responsive
- The change does not break existing workout flows

## Reporting bugs

Please open an issue with:

- steps to reproduce
- browser/device used
- expected behavior
- actual behavior
- screenshots or recordings if possible

## Suggesting features

Feature ideas are welcome. Please explain:

- the problem it solves
- why it matters for workout flow
- who would benefit from it
- whether it fits the app's mobile-first philosophy

Thank you for helping RunCue grow.
